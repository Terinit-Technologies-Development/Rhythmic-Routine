## 2. Verified Architectural Capabilities

- [x] **Overnight Protection Continuity:** Evening Wind-Down transitions directly into Overnight Protection; unlocks only at Morning Buffer end.
- [x] **Per-Risk-App Daily Allowance:** Default 30 minutes, 15-minute step increments, 0-minute minimum.
- [x] **Once-Per-Day Allowance Edit Guard:** Persisted via `lastEditedDateKey`; second same-day edits strictly rejected by domain rules.
- [x] **Single-Day Allowance Increase Guard:** Capped at +15 minutes above persisted allowance; larger single-day increases rejected.
- [x] **Multi-Step Reduction Rules:** Reductions of any valid 15-minute step (e.g. 30→15, 30→0) permitted on first daily edit.
- [x] **Native Android Ledger:** Foreground tracking driven by Accessibility window state changes; Touch Grass excluded from Risk usage.
- [x] **Access Lease Accounting:** Usage during leases counted in daily ledger; Touch Grass suppressed during lease and restored on expiry.
- [x] **Real Native Insights:** 7 local calendar days query (`getSevenDayWindowStart`); Android UsageStats replaces engine Risk history without double-counting.
- [x] **Telemetry Error Truthfulness:** Stale usage suppressed on native snapshot failure (`—` / `Usage unavailable`); restores upon subsequent success.
- [x] **Android First/Final Risk Use:** Evaluates strictly from observed UsageStats when available; never falls back to engine history.
- [x] **Factual Real-Data Copy:** Takeaway copy strictly reflects observed device routines and breaks without speculative claims.
- [x] **Reduced Native Work:** 60-second Risk Group projection only while JS is alive; native routine/cooldown scheduling independent of JS timers.

## 3. Privacy & Permission Audit

- [x] **Zero Background Service Permissions:** `FOREGROUND_SERVICE` and `SCHEDULE_EXACT_ALARM` strictly absent.
- [x] **Zero Broad Package Query Permissions:** `QUERY_ALL_PACKAGES` strictly absent; launcher queries used.
- [x] **Zero System Alert Overlay Permissions in Enforcement:** `SYSTEM_ALERT_WINDOW` not used for blocking; opaque `RhythmOverlayActivity` used.

- [x] **No Node-Tree Traversal:** Zero screen content inspection; package identity only.
- [x] **No Cloud Telemetry:** 100% on-device telemetry and storage.
