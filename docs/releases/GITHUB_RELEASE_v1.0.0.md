# Rhythmic-Routine v1.0.0 — Experimental V1

Rhythmic-Routine v1.0.0 is the first feature-complete release of our local-first digital-wellbeing application.

Rhythmic-Routine is designed around **intentional digital rhythm** rather than arbitrary countdown limits or daily screen-time lockouts.

---

## 🌿 Highlights

- **Morning Buffer & Evening Wind-Down:** Create structured daily boundaries to protect morning focus and nighttime rest.
- **Risk Groups & Continuous Sessions:** Monitor scroll-heavy apps collectively (e.g. Social, Video) with 5-minute inactivity gap accounting.
- **Touch Grass Recovery:** Calming, fullscreen opaque (`#FAF7F0`) pause screens that invite restorative breaks and route back to Android Home.
- **Temporary Access Leases:** Urgent overrides without losing your underlying cooldown or routine status.
- **Inviolable Essential Apps:** Core utilities (*Phone, Maps, Emergency Tools*) are mathematically exempt from all restrictions.
- **Local-First Privacy:** Zero cloud accounts, zero telemetry, zero analytics SDKs, and 100% on-device SQLite storage.
- **Native Android Accessibility & Discovery:** Discovers launchable apps via targeted `<queries>` and enforces calm interventions on-device.

---

## 📱 Platform Qualification Status

- **Android:** **`PHYSICAL_DEVICE_VERIFIED`** — Qualified on physical Android hardware using self-contained standalone APK packaging.
- **iOS:** **`Experimental Foundation`** — Source architecture implemented using Screen Time ManagedSettings and DeviceActivity extensions. Not physically validated on Apple hardware.
- **Web:** Local interactive demonstration environment.
