## 1. Candidate Scope & Architectural Invariants

Rhythmic-Routine v1.0.1 integrates the following verified architectural capabilities:

1. **Evening → Overnight → Morning Protection Continuity:**
   - Evening Wind-Down transitions directly into Overnight Protection upon window end.
   - Overnight locks all Risk apps unconditionally until Morning Buffer.
   - Open Day is derived strictly during daytime hours between Morning Buffer and Evening Wind-Down.
2. **Per-Risk-App Daily Allowance:**
   - 30-minute default allowance per Risk app.
   - 15-minute allowance step unit, 0-minute minimum.
   - Once-per-day allowance edit lock (persisted via `lastEditedDateKey`).
   - Maximum single-day increase capped at +15 minutes.
   - Multi-step daily reductions permitted.
3. **Android Native Daily Usage Ledger:**
   - Foreground app accumulation strictly driven by Accessibility window state transitions.
   - Touch Grass time excluded from Risk usage.
   - Usage during Access Leases counted in daily ledger.
   - Native deadline alarm calculates exact remaining time to zero; no polling.
4. **Real Native Insights:**
   - 7 local calendar days query (`getSevenDayWindowStart`), resilient across DST boundaries.
   - Android UsageStats replaces engine Risk history without summation or double-counting.
   - Stale usage suppressed on native telemetry error (`—` / `Usage unavailable`).
   - Android First/Final use stays with observed UsageStats when available; never falls back to engine history.
5. **Independent Cooldown & Routine Ownership:**
   - Android native layer unions routine windows, cooldowns, and daily allowances independently.
   - Access Lease suppresses effective restriction without mutating base registry.
   - Reduced Android recurring work; 60s group session projection only while JS is alive.
